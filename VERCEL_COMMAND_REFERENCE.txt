  PASO 1: ABRIR TERMINAL EN LA CARPETA DEL PROYECTO (1 min)

Opción B: Haz clic derecho en la carpeta del proyecto → "Open in Terminal"

================================================================================
  PASO 2: INICIALIZAR GIT (3 minutos)
================================================================================

Copia y pega EXACTAMENTE estos comandos en orden:

  git init

  git config user.name "Edwin Vinicio Arcos"

  git config user.email "vinicioarcos123@gmail.com"

  git add .

  git commit -m "Initial commit: Portafolio profesional v1.0"

Deberías ver algo como:
  [master (root-commit) abc1234] Initial commit...
  XX files changed, XXXXX insertions(+)

================================================================================
  PASO 3: CREAR REPOSITORIO EN GITHUB (5 minutos)
================================================================================

1. Abre https://github.com/new en tu navegador

2. Completa así:
   Repository name:  portafolio-economista
   Description:      Portafolio profesional de economista
   Visibility:       ✅ Public
   (Deja todo lo demás en blanco)

3. Click "Create repository"

4. GitHub mostrará estos comandos (CÓPIALOS):
   git remote add origin https://github.com/TU_USUARIO/portafolio-economista.git
   git branch -M main
   git push -u origin main

================================================================================
  PASO 4: CONECTAR A GITHUB (2 minutos)
================================================================================

Vuelve a tu terminal y pega estos 3 comandos:

  git remote add origin https://github.com/TU_USUARIO/portafolio-economista.git

  git branch -M main

  git push -u origin main

IMPORTANTE: Reemplaza TU_USUARIO con tu username de GitHub

Ejemplo:
  git remote add origin https://github.com/vinicio-arcos/portafolio-economista.git
  git branch -M main
  git push -u origin main

Si te pide autenticación, una ventana en el navegador se abrirá (sigue las instrucciones)

Verás:
  Enumerating objects: ...
  ...
  Branch 'main' set up to track remote branch 'main' from 'origin'.

================================================================================
  PASO 5: DESPLEGAR EN VERCEL (4 minutos)
================================================================================

1. Abre https://vercel.com/new en tu navegador

2. Si es tu primera vez:
   - Click "Continue with GitHub"
   - Autoriza a Vercel

3. Busca tu repositorio:
   Escribe: portafolio-economista
   Click en "Import"

4. Configuración automática:
   (Vercel detecta Next.js automáticamente)
   - Framework: Next.js ✓
   - Root Directory: ./ ✓
   - Build Command: npm run build ✓
   - Output Directory: .next ✓

5. Click "Deploy"

6. ESPERA 2-3 MINUTOS

   Verás: "Deployment successful"
   Tu URL será: https://portafolio-economista.vercel.app

================================================================================
  🆘 SOLUCIÓN RÁPIDA DE PROBLEMAS
================================================================================

"git is not recognized"
→ Descarga https://git-scm.com/download/windows

"fatal: not a git repository"
→ Verifica que estés en la carpeta correcta con: cd "C:\Users\..."

"Permission denied (publickey)"
→ En vez de SSH, usa HTTPS:
   git remote set-url origin https://github.com/TU_USUARIO/portafolio-economista.git

El build falla en Vercel
→ Mira los logs en tu proyecto de Vercel (Deployments → ver error)
