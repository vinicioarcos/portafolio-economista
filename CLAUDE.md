# CLAUDE

## Contexto del proyecto
Este repositorio contiene un portafolio web en Next.js para presentar el perfil, servicios, publicaciones, proyectos y cursos de un economista.

## Prioridades
- Resaltar credibilidad profesional.
- Hacer facil la actualizacion de contenido.
- Mantener una experiencia rapida, limpia y responsive.

## Notas
- Los activos en `public/cv` y `public/images` son placeholders iniciales.
- Si se agrega contenido nuevo, hacerlo primero en `src/data`.
